# Analysis outputs

## `Results_Preprocessing/`

Contains the station-inclusion record and is the default destination for preprocessing outputs. The final screening threshold retains stations with at least 700 valid collocated days.

## `Results_3CH, ETC & DC/`

Contains the principal uncertainty-analysis outputs used by the manuscript, including:

- the core station-level 3CH/ETC/DC workbook;
- regional and continental summary CSV files;
- the integrated 27-station statistics table with mean PWV and nRMSE;
- regional-ranking analysis outputs.

`PWV_Statistics_Results_with_nRMSE2.csv` is the direct input to the final nRMSE/ETC figures and to `Code/reproduce_manuscript_summaries.py`.

## `Derived_nRMSE_Summaries/`

Generated by `Code/reproduce_manuscript_summaries.py`. These files are designed to make the reviewer-facing station-to-region-to-continent analysis reproducible from a single integrated 27-station table.
