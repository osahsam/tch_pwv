# Code directory

This directory contains the preprocessing, uncertainty-analysis, statistical-comparison, and plotting scripts used for the manuscript.

## Recommended workflow

### 1. Outlier detection and cleaning

`OUTLIER_Detrending_nonlinear analysis_v3_5_1.py`

- Input: `Data/Collocated_PWVs (unpreprocessed)/PWVdata_27 stations(unpreprocessed).zip`
- Default method configuration includes Hampel/IQR/Z-score comparison with the selected cleaning strategy documented in the script.
- Output: `Analysis/Results_Preprocessing/Results_Outlier detection & removal/`
- The cleaned station files contain `IGS_Hampel_clean`, `VMF3_Hampel_clean`, and `ERA5_Hampel_clean`.

### 2. Core 3CH / ETC / DC / nRMSE calculation

`PWV_Analysis_TCH_ETC_DC_updated4.m`

This is the final MATLAB analysis script. It computes:

- 3CH RMSE for IGS, ERA5, and VMF3;
- ETC RMSE and ETC correlation coefficient for each dataset;
- ERA5-referenced direct-comparison RMSE and correlation;
- station mean ERA5 PWV;
- 3CH-, ETC-, and DC-based nRMSE metrics.

When prompted in MATLAB, select the cleaned station-data directory generated by the outlier-cleaning script. The final script reads the `*_Hampel_clean` PWV columns.

### 3. Detrending/STL diagnostics

`Detrending_analysis_stl_v3.py`

This script provides the STL decomposition, trend, stationarity, variance-component, and detrending diagnostics used to evaluate preprocessing sensitivity. It supports repository-relative defaults as well as command-line/YAML overrides. The final 3CH/ETC/DC script uses the Hampel-cleaned series directly; the STL analysis is therefore a diagnostic/sensitivity component rather than a mandatory numerical input to the final uncertainty calculations.

### 4. Final manuscript summary tables

`reproduce_manuscript_summaries.py`

This portable script reads the final integrated 27-station statistics and regenerates:

- regional ETC RMSE/nRMSE/R summaries;
- continental ETC means;
- network-wide Pearson correlations with mean PWV;
- regional IGS PWV–error correlations where station count permits;
- pooled RMSE/nRMSE/ETC-R and SNR-related relationships;
- a repository validation report.

Run:

```bash
python Code/reproduce_manuscript_summaries.py
```

### 5. ETC/nRMSE figure suite

`etc_nrmse_figures.py`

Reads:

- `Analysis/Results_3CH, ETC & DC/PWV_Statistics_Results_with_nRMSE2.csv`
- `Data/IGS STATIONS-Africa_27sta.csv`

Outputs high-resolution PNG/PDF figures to `Figures/generated_etc_nrmse/`. The manuscript figures correspond to the following generated panels:

| Generated figure | Manuscript role |
|---|---|
| Figure A2.4 | station-level absolute vs normalised ETC RMSE |
| Figure A2b | regional ETC error along the humidity gradient |
| Figure A3 | continental ETC performance summary |
| Figure A7 | RMSE/nRMSE relationship with ETC correlation and SNR-related quantity |
| Figure A4 | network-wide dependence on mean PWV |

The plotting labels use **Pearson `r`** for correlations calculated with `pandas.Series.corr()`/Pearson correlation.

## Additional plotting scripts

The remaining `TCH_*` Python scripts reproduce the 3CH/ETC/DC station, spatial, regional, ranking, and boxplot figures. Their I/O paths have been converted to repository-relative paths so that they can be run from a cloned copy of the repository without editing local drive letters.

## MATLAB multiple-comparison test

`mct.m` performs the multiple-comparison analysis. The prepared input is:

`Data/MCT/MCTdata_RMSE-3CH_ETC_DC.csv`

## Software

- MATLAB R2016b or later for the core 3CH/ETC/DC and MCT scripts.
- Python dependencies are listed in the root `requirements.txt`.
